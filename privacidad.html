Política de privacidad

Información sobre los datos tratados al consultar o utilizar las funciones disponibles de ONLY LORD.

Datos tratados y origen

Según la función que el visitante elija, puede proporcionar nombre, correo, país, teléfono o WhatsApp, referencias musicales, detalles de pedidos y el contenido de un mensaje. El carrito se conserva en el almacenamiento local del navegador; la página de detalle usa almacenamiento de sesión para recordar la ficha seleccionada. Estos datos del carrito o detalle no se envían por sí solos al vendedor.

El formulario de contacto prepara un correo en la aplicación de correo del usuario y el formulario de pedido o carrito prepara un mensaje de WhatsApp. No existe en este sitio un servidor que reciba automáticamente esos formularios: los datos solo se comparten si el usuario decide enviarlos desde el servicio elegido. Las interacciones posteriores por correo o WhatsApp pueden contener la información que el usuario incluya.

  • Responder consultas y solicitudes de presupuesto.

Servicios externos y datos técnicos

El sitio está publicado como página estática y las páginas revisadas cargan el script de Cloudflare Web Analytics. Cloudflare puede recibir información técnica de las solicitudes; la configuración exacta, conservación y tratamiento dependen del servicio y de la cuenta de publicación. El código revisado no contiene una llamada directa a una API de correo, no configura dLocal Go ni contiene código que lea o escriba cookies. Esto no permite afirmar que servicios externos, navegadores o la plataforma de publicación no utilicen cookies o registros técnicos.

Si el usuario sigue un enlace o envía un mensaje mediante correo, WhatsApp, YouTube u otra red social, el servicio correspondiente procesa la interacción bajo sus propias condiciones y políticas. Algunos detalles de producto pueden cargar contenido de YouTube. dLocal Go no está habilitado como proveedor de pago en este sitio.

Conservación y seguridad

El sitio no recibe automáticamente los campos de los formularios ni procesa información de tarjetas. La conservación de mensajes y referencias dependerá de la comunicación directa, de las obligaciones aplicables y de los proveedores que participen. No compartas números completos de tarjetas, CVV, claves o contraseñas. Los comprobantes, cuando sean necesarios para identificar un pago manual, deben enviarse de forma privada y solo con la información pertinente.

Para localizar una conversación, indica el correo y una referencia suficiente; no envíes datos sensibles innecesarios. Las solicitudes se evaluarán conforme a las obligaciones aplicables. Esta política no constituye una declaración de certificación o cumplimiento legal verificado.
